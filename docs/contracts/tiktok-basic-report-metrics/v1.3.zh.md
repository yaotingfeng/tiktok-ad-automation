# SKAN 指标
**SKAN 指标是 SKAN 专属推广系列的数据。** 了解[专属推广系列配额](https://business-api.tiktok.com/portal/docs?id=1740029173531649#item-link-专属推广系列配额)和[专属推广系列报表指标](https://business-api.tiktok.com/portal/docs?id=1740029173531649#item-link-专属推广系列报表指标)。SKAN 指标支持推广系列、广告组与广告层级，且不支持小时级数据。

若想确认某个专属推广系列是否为 SKAN 专属推广系列，可使用[/campaign/get/](https://business-api.tiktok.com/portal/docs?id=1739315828649986)并检查返回的 `disable_skan_campaign` 是否为 `false`。

> <span style="color: DodgerBlue">**注意**</span><br>
> SKAN 指标仅为 SKAN 专属推广系列展示实际值。对于非 SKAN 专属推广系列和普通推广系列， 这些指标的值会显示为 `0`。

若想确认某个专属推广系列是否为高级专属推广系列，可使用[/campaign/get/](https://business-api.tiktok.com/portal/docs?id=1739315828649986) 并检查返回的 `is_advanced_dedicated_campaign` 是否为 `true`。
