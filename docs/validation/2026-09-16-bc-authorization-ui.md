# BC 使用授权统一入口与关联 BC 面板

## 已批准的操作逻辑

- 不增加独立页面。在“账户与授权 → 广告账户”顶部显示当前 BC、使用授权、接入方式和授权状态；租户管理员通过“更换授权”侧栏保存该 BC 的配置，普通成员只读。
- BC 是业务范围；API / MCP 是授权的接入方式。同一 BC 可以关联多份授权，但账户查询、新上传和新搭建共用该 BC 保存的授权，不在各业务页临时选择。
- 新增授权不自动替换配置；没有配置时需明确保存，唯一授权也不静默选中。后续分页中的默认授权仍须读取到，不能取第一页首条代替。
- 授权管理保留授权、同步、重新授权和解绑；关联 BC 表只展示是否使用此授权，更换操作统一回到广告账户页。
- 新草稿显式提交 `execution_connection_id: null`，由后端在开始准备时使用 BC 配置。编辑旧草稿并保存时清除单独的授权偏好；已有准备、预览及执行任务保留原冻结授权。没有修改后端路由、冻结或重试契约。

## 界面与实现

- 删除账户与搭建页的 `BCConnectionPicker`，新增 `BCAuthorization` 组合现有管理侧栏、shadcn 卡片及单选组件，复用默认授权保存接口及其权限、归属与绑定校验。
- 授权选项展示名称、API / MCP、状态、最近授权时间和编号尾号，不使用完整 UUID 作为主要选择文案。没有真实名称时显示“未命名授权”，不虚构授权人。
- 更换前不发写请求；保存成功后回读 BC 与账户目录。角色无权限、查询失败、保存被拒绝及关闭未保存侧栏均有对应状态。
- 连接详情宽度从桌面最大 576px 扩为 1024px，BC 名称列限制宽度并允许换行，保留最小宽度避免手机端编号纵向挤压。900px / 1440px 下“同步账户”按钮无需横向滚动；390px 显式提示左右滑动。
- 搭建与素材的缺失授权、授权不可用及未完成 BC 接入错误提示统一指向“账户与授权”。
