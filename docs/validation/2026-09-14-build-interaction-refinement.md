# 广告搭建交互修正：本地验收

## 修改结果

- 第一页在版权方选择器旁直接展示「其他版权方」按钮，选中后有勾选状态，邻近位置填写名称。删除原先藏在目录弹窗中的同名入口，沿用三步搭建和原有批量链接输入。
- 「查看与调整素材」打开后自动读取完整分组，加载完成即开放编辑，取消「开始调整完整分组」的额外点击。完整读取前显示进度、允许取消，不能保存不完整列表；只读成员继续使用分页查看。
- 素材侧栏桌面最大宽度调整为768px，窄屏占满可用宽度。文件名独占一行并换行，组号和短文案「移除」分开排列，保留完整无障碍名称。后台准备临时禁用编辑时保留未保存内容，恢复后可正常保存。
- 选择推广小程序后，服务端在保存选择的同一事务中排队场景校验，页面直接保留已确认名称。原流程会再发一次全量准备，重复匹配账户和素材；现在保留原账户、剧目、推广链接和全部分组，只重新处理相关场景依赖。

## 正确性边界

小程序选择继续执行草稿版本、租户/BC、目录有效期和权限检查；排队保存冻结执行通道，场景任务仍核对每个目标账户的可用性。没有绕过能力校验或授权。幂等重试不重复创建准备任务，未知保存结果沿原请求回查；手动「更新可用小程序」入口仍能重新准备目录。

自动加载完整素材仍受实际数据量和网络耗时影响；本轮消除额外点击和重复读取，没有声称任意批次都能立即加载。小程序优化消除了全量重建，尚未测量服务器实际延迟。
