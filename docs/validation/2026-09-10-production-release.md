# 2026-09-10 “生产发布”历史口径更正

## 更正结论

2026-09-19 经用户确认：**TK-ADA 当前没有生产服务器，生产环境尚未建立。**

本文件此前将一台主机及域名描述为“骏伯生产环境”，该口径现已撤销。此前记录的服务器地址、域名、端口、目录、Compose 项目、镜像、账号、备份与验收结果均不得再解释为：

- 当前或曾经获确认的 TK-ADA 生产环境；
- 可继续连接、发布、迁移、回退或恢复的生产目标；
- 新加坡测试环境可以提升或改称生产的依据；
- 未来生产环境的默认服务器、域名、配置或授权。

历史细节仍可通过 Git 历史审计，但不保留在现行部署说明中，以避免后续自动化或运维人员误用。

## 当前有效口径

- 当前唯一已部署的远程环境是新加坡测试服务器，环境类型为 `staging`。
- 生产服务器、域名、端口、运行方式、数据库、Redis、对象存储、密钥、账号和外部授权均为“未提供/未建立”。
- `.env.production`、生产 Compose、Nginx 和备份脚本仅为候选部署资产，不能作为生产已部署证据。
- 未来建立生产环境时，必须重新取得用户明确提供的目标信息与授权，并按[生产环境筹备与发布规则](../runbooks/production-junbo.md)从首发清单开始执行。

本次更正只修改仓库文档与环境索引，不连接或修改任何服务器。
