# 冻结预览整段提速与可见进度（已发布新加坡测试服）

## 范围与行为

用户确认优化预览公共检查，并增加加载动画、真实进度、阶段、耗时和异常提示。不跳过权限、链接、素材检查；不生成或提交真实广告。本轮基线为 `a7b5e0b`（线上功能版本 `badccc2`）。

- `continue_preview` 显式启用短批次本地读取复用。键包含函数、Session、事务、租户/操作者、完整冻结路由、账户、操作类型等实际参数；只保存成功值，3 秒后不再复用，最多 1,024 个键，异常/退出即清理。外部写任务不启用这个范围。
- 退出前使用全新的读取范围复核计算阶段用过的检查，公共依赖只读取一次最新值；撤权、绑定改变、Mini 改变、场景结果改变或来源冷却改变会拒绝保存当前批次。下一轮重新读取，不做跨任务权限缓存。
- 同账户/Mini 的不可变场景快照可共享，但每个链接的版权方与目标分别核实；历史链接证据仍隔离。非批次读取缺少共享场景时不增加二次查询。MiniTarget 强制刷新，覆盖其他事务修改和强引用旧 ORM 对象的情况。
- 只读主素材账户选择与提交时的持久选择分开，后者不复用、不绕过锁/冷却。冻结执行路由在父草稿锁下每轮读取一次，传入组合展开。
- 默认计算时间预算由 20 秒缩为 3 秒，及时提交阶段与计数；仍每轮最多 200 步。单次 SQL、单步计算与最终复核可能使整轮超过 3 秒，不承诺严格心跳周期。
- `generation_progress` 返回阶段、完成组合数、固定总数、最后提交时间。分母在创建时随草稿锁固定；完成数只统计 `complete=True`，包括阻断组合。历史未完成记录没有固定分母时返回 null，不读新草稿猜测历史总数。无数据库迁移、依赖或环境开关变更。
- 前端沿用 shadcn：旋转加载图标、阶段、真实组合进度、耗时；未知总数不造百分比，全部组合已处理但未冻结时仍显示汇总状态。30 秒未推进、请求异常、403 权限失效分别提示，刷新只 GET 原预览。FROZEN/FAILED 后停止动画与计时。
