# 预览必填校验与跨 BC 素材检查优化（本地）

用户反馈新加坡测试站点生成预览过慢，未选择推广小程序仍能进入预览。服务器只读记录显示该批 22 剧、10 账户，从北京时间 11:05:36 到 11:09:24，后台连续执行 11 轮；没有正式广告提交。预览在本地逐步展开组合，不是在等待 TikTok 创建广告。

## 修改

- 新建预览在任何预览记录、编号及 outbox 写入之前批量检查所有剧目推广链接的已确认 Mini；缺少选择或存在不同目标时返回中文 HTTP 409。已有相同草稿版本预览仍按原幂等身份恢复。单个链接过期继续按剧目隔离，不将此情况升级为整批失败。
- 准备页与小程序选择器复用同一查询。草稿 READY、小程序 selected 且最新查询成功后才开放生成按钮；未选择、目录加载中、目录不可用、目标冲突、查询失败及选择后的准备期间均禁用并解释原因。名称回显仅属于保存回执对应的草稿版本，不拿乐观名称作为可生成依据。
- 生成页使用现有服务端 `total_unit_count` 显示已完成组合数，不伪造百分比或最终预算。
- 跨 BC 素材检查将同一有界组（最多 50 项）共享的主账户选择、权限和执行配置检查从逐视频执行改为本次调用内一次。素材摘要、容量、来源、目标映射等仍逐项验证；后续调用重新检查权限与冷却，不添加跨请求权限缓存。

## 性能证据

真实本地 PostgreSQL、合成跨 BC 库存、无平台网络请求。新增回归先在旧实现上失败：单条 80 次查询，25 条 1,088 次查询（其中重复公共查询 42 次/额外素材）。相同测试在新实现单条/25 条均为 80 次查询，减少约 92.6%。

25 条测量耗时：旧实现约 0.317 秒；新实现首次约 0.023 秒、复测约 0.038 秒。这只是该素材检查环节的本机耗时，不代表新加坡整批预览耗时或真实广告搭建速度。现有每轮 20 秒/200 步预算、队列配置保持原值。
