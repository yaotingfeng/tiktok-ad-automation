# 批量复制本地实现与验证

依据：用户已批准独立表格原型并要求实施。代码在既有main工作区按明确文件所有权整合，未创建分支；保留原有经营核验文档及TypeScript编译缓存。实现方案见[设计](../superpowers/specs/2026-11-10-campaign-copy-design.md)和[实施计划](../superpowers/plans/2026-11-10-campaign-copy.md)。

## 功能

- 广告报表系列维度勾选后进入独立复制配置页；来源冻结，逐行修改预算、ROAS、账户与份数，支持选中行批量填值。
- 账户沿用AccountPicker搜索/筛选/多选，外层明确保存/取消和移除；定向复用TargetingForm，排期复用DraftSchedule，素材使用侧栏。没有手填文案或重新抽文案。
- 持久复制草稿、修订冲突保护、同键同意图重放、未知响应重试；后台每轮准备一个独立副本。每源/目标/份次各有独立子预览，原执行器创建/回读/恢复，父页给出任务链接。
- 来源当前设置、历史推广链路及素材关联分开核验；保留真实广告归属与实际文案，素材过滤不创建空广告/组。目标使用经过核验的本地映射/原素材准备路径，不能挪用源VID。
- 来源及子预览按组展示实际预算/ROAS/定向；多组不同值不伪装成首组单价。父批次与直接子预览首次提交均复核来源和原读取路由。
- 当前仅支持同币种、可完整核实的升级Smart+小程序视频系列；普通/旧Smart+、轮播、外部来源缺可信关联、多身份/链接/CTA、未知创建设置或无法核实的定制封面在行内明确阻断。手工定向等超出现有创建能力的设置不静默改为默认值。
