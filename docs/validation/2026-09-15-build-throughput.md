## 代码处理

- 封面单任务复用一次 gateway 会话，每个物理请求仍独立检查授权、配额、目标 VID、摘要、claim 和截止时间，不做跨租户/跨任务客户端缓存。
- 完整图片上传回执可直接发布 READY；必须具备实际 ID、摘要、严格尺寸/布尔字段且匹配已核实视频比例。缺项保留已知 ID，只读核查，不能重复上传。
- 目标没有图片时，可从同租户/BC/素材的历史 READY 记录取得候选；目标视频映射必须新鲜，源当前 VID、路由、摘要和权限仍要匹配。历史源记录仅为提示，不继承其时效；当前目标账户图片读取才是新的可用证据。成功可用一条图片读取完成，不导入图片。
- 复用 READY 用候选 ID 表示实际已核实图片，不伪造上传时间或上传回执；广告最后一道检查同时支持这种证据。未核实候选不能创建广告。旧候选读取错误或不一致保持只读，不改成重新导入。
- 瞬时未发送故障和只读故障最多连续尝试三次（间隔 5/10 秒）；成功 READY 清零连续失败计数。初次无 arm/known ID/追加回执、已有持久候选的图片读错同样可自动继续只读。已发送上传 UNKNOWN 绝不重传；权限、契约和永久错误不作网络重试。
- 单元唤醒合并有效在途投递；多发布器按需领取租户锁，避免预锁未服务租户。量化结果与单发布器额外成本见[调度容量验证](2026-09-15-dispatch-capacity.md)。
