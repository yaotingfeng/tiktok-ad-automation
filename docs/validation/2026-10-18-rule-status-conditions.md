# 2026-10-18 自动规则状态条件与素材恢复父级保护

## 授权与范围

用户要求去掉广告账户判断项，把启停判断统一称为“状态”，发布生产，再为 junbo 第四条“04 素材回收恢复”增加“广告状态 是 开启”。恢复规则继续保留当前停用状态，模式 AUTO 不变；不即时执行候选，不回退此前 240 项素材。

## 实现

- 可选对象属性为系列状态、广告组状态、广告状态、素材状态，值为开启（ENABLE）或暂停（DISABLE），仅支持 EQ，不使用报表时间周期，也不把状态转成数字。上级属性可用于下级对象；状态条件仅 EACH 使用，不用合计成员中的第一项冒充全体状态。未加入广告账户状态。
- 下拉、规则摘要、试运行及待确认指标统一显示中文状态。属性仍占现有最多五个条件之一。
- 每个状态表示该层对象自身的操作状态；系列已暂停而广告自身开启时，广告状态仍为开启，系列状态为暂停。
- 素材 ENABLE 内置要求广告、广告组、系列均开启；PAUSED、SELECTED 及由上层展开素材的路径均生效。未知上级不生成可执行恢复目标，素材范围内缺失父级沿用待数据说明。反向冲突复核仍能忽略作用状态。
- 提交管理任务前重新读取租户、账户内的目录父级链；父级暂停/不明则记 SKIPPED_PARENT_STATUS，跳过数合并到现有精简通知，不额外发消息。目录状态来自已同步数据，并非本轮逐个请求平台的实时状态；不承诺识别平台外人工单独暂停素材的来源。
- 无表结构迁移，无新增部署开关。九角色沿用线上四个 true；自动规则仍按租户/BC、权限和当前计划执行。
