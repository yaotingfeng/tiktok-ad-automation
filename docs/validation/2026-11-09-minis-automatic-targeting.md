# Minis自动定向修复与生产发布

## 原因和修改

官方Mini Dramas Non-Catalog专用创建合同仅允许AUTOMATIC或省略。生产暂停态对照：相同账户、原系列、国家、零日最低ROAS，自动成功，MANUAL失败；自动+最低25岁+英语已成功并完整回读实际条件，未启用或创建广告。

新预览固定自动模式，国家及语言保持；18+（默认或完整成人集合）、25+集合映射为spc_audience_age。精细年龄/严格性别不能静默扩大，在策略保存、草稿修改与预览入口明确拒绝，页面要求显式修正。策略存储结构不变；新增内部最低年龄字段贯穿SDK/MCP编解码及严格回读，不从请求或默认值补造缺失的远端证据。旧MANUAL可查历史、发送前明确NOT_SENT，原任务不改写/自动重投。场景约束v8刷新新准备缓存。

审查发现并修复：新错误码注册422与公开消息；旧自动预览在执行重核时仅比较规范化平台已存在的AUTO/18+默认语义，保留原冻结正文，不把MANUAL或精细限制等同自动。生产发布前只读观察到2个RUNNING提交，因此新增默认意图保持及MANUAL仍阻断的回归。
