# 2026-10-30 搭建成功直接进入广告目录

## 确认的行为

用户明确选择：创建结果立即写入目录，不在创建后额外触发同步；后续定时同步按原对象身份更新。系列、广告组、广告以及广告素材关联均适用。保留报表原有“显示无数据对象”筛选：尚无报表事实的新对象需勾选后查看，不改变默认筛选和金额口径。

## 实现

- 创建成功回执与目录初次插入同事务提交；创建超时后经原回读核实成功的路径也补齐目录。
- 按租户、账户、对象类型和平台 ID 去重。初次写入使用 `ON CONFLICT DO NOTHING`，重复或晚到回执不覆盖已有平台同步结果；后续定时同步继续使用既有时间水位和更新逻辑。
- 保存父子关系、已接受的请求配置、系列名称解析、真实视频/图片使用关系；同广告素材批量插入。严格按冻结租户、BC、连接和实际目标账户匹配已完成素材依赖，唯一匹配时附带本地素材 ID 与文件名。
- 创建与读取共用素材身份解析。视频封面不作为图片主素材；轮播保留图片顺序和配乐。没有平台广告内素材 ID 或创意 ID 时不猜填，不开启依赖这些 ID 的独立素材操作。
- 仅使用已确认的操作状态；审核和投放状态没有证据时为空。UNKNOWN、核查不一致、跨租户/BC/连接/账户均不能插入目录。
- 不创建目录或报表任务、不推进报表同步水位，不改变原配额、开关、调度、API 或数据库结构。
