# 素材分发与可识别命名

用户已明确：同 BC 必须原生共享，跨 BC 才使用 URL 上传；官方 API 与服务器官方 MCP 一致。保留现有授权、租户边界、冻结路由和未知写入恢复，不做失败自动转上传，不新增功能开关。

1. 核对现有授权判断；补齐版权方应用的管理员 Minis 配置入口。
2. 接通双通道 `creative/asset/share`，发送时核对同一授权对源/目标账户的操作权限。共享使用 MID；目标账户的实际 VID 从查询结果获取，不复制源 VID。
3. 来源选择优先当前 BC；仅在同租户且可信内容摘要完全相同、另一个已接入 BC 有明确来源时使用 URL 转存。跨 BC 来源保存独立冻结路由，迁移仅调整来源路由约束，目标/租户约束保持。
4. 上传名称保留原名及集数，长度超限从中间压缩；短后缀用于未知结果关联。广告视频传入原文件名。已经发送的历史请求保持冻结，不改写在线广告。
5. 验证双通道传输、同/跨 BC、权限撤销、未知结果不重复发送、命名及配置入口；按部署手册备份、发版并核对已有开关。
