# 每日操作日志与自动赔付 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话执行，用户已批准实施，无需重复方案确认。

**Goal:** 保存官方账户操作日志，以版本化的每日依据自动核算历史与T+1赔付，并显示覆盖缺口。
**Architecture:** 复用 ReportSyncJob / sync_control、官方 SDK gateway、现有经营发布围栏；独立日志事实、原文归档和配置锚点。每日刷新最近7个完整日，历史沿用经营起点。当前工作区开发，不推送或发布。
**Tech Stack:** Python / SQLModel / PostgreSQL / Redis / Celery / React / shadcn。
**Spec:** ../specs/2026-11-09-operation-log-compensation-design.md

## Global Constraints

遵守仓库 AGENTS.md，保留当前分支及其他会话改动。无真实广告、凭据或生产写入。物理请求分别准入，等待释放租约；日志完整性与日报水位分离；事实租户+账户、经营结果明确BC。原文私有，不入Git。成功空结果须可验证，未知格式失败关闭。不可用当前出价代替历史出价。新Alembic迁移，不改旧迁移。精确暂存并本地提交。

## Review Focus

1. 同分钟同额多次真实操作、跨窗口重放：解析/存储测试。
2. DST实际30日跨度、当地日归属：窗口/每日还原测试。
3. 任务重启、失效冻结授权、原子发布：真实PG/Redis任务测试。
4. 缺锚点、断链、未知来源和暂停再恢复：每日证据测试。
5. 日依据代数、旧导出不变、条件预计与资格待核：经营发布与查询/UI测试。

### Task 1: 官方回执合同、CSV解析和时间窗口

**Interfaces:** ChangeLogReader(create/check/download)返回严格合同；解析输出不可变事件和内容摘要；账户当地窗口转换UTC。
- 从既有私有导出核实check/download字段及CSV表头/空结果，不复制真实值。
- 先写失败测试覆盖BOM、多行JSON、汇总行、重复事件、非法格式、时区边界。
- 实现独立contracts/adapters和解析模块，验证单测与静态检查。

### Task 2: 日志持久化和既有同步状态机

**Interfaces:** ReportSyncJob kind=operation_log；不可变导出及事件、日期覆盖与配置观察；原子发布和修订。
- 新迁移建立事实/覆盖/观察表，注册模型。
- 官方SDK固定端点注册，复用冻结路由/额度，每次调用计数。
- 先写传输边界与真实PG测试；实现CREATE/CHECK/DOWNLOAD、退避恢复、严格发布、原文私有归档。
- 接入sync_control路由、计划及worker，独立日志完成覆盖；验证授权变代、重放、空/失败及多租户。

### Task 3: 每日还原及自动赔付依据

**Interfaces:** 可信配置观察+完整变更链→每日最低ROAS/负向操作/归因；不可变依据版本→BusinessRun冻结输入。
- 先写还原/公式边界失败用例；实现双向链校验、同分钟歧义和负向操作识别。
- 复用实际目录配置及成功冻结搭建/管理回读作为观察，禁止策略反投影。
- 分离条件金额与最终资格，确定0优先；旧人工记录保留审计，修订绑定更正。
- 来源变化按范围失效，经营快照冻结版本；回归历史导出和分页一致性。

### Task 4: 历史/T+1调度、查询和界面覆盖

**Interfaces:** 最近7完整日与历史持久需求→共用日志任务；经营查询返回条件预计、小计和缺失说明。
- 先写历史/T+1端到端测试，复用已有账户归属与公平调度。
- 历史请求补缺、配置开关语义和部署边界文档。
- 复用预计赔付列与提示，显示小计、未知及资格待核，保护基础金额和新剧补贴。
- 生成客户端，针对性后端/UI测试、类型与构建检查。

### Task 5: 整体验证、审阅和聚焦提交

**Interfaces:** 本地证据与真实生产验收分别记录。
- 按计划运行相关真实PG/Redis套件；不调用实时平台接口。
- 一位独立审阅者检查整体实现与设计，修复重要问题并回归。
- 更新implementation-progress与验证记录、方案批准状态。检查仓库/暂存差异后聚焦提交，不推送、不发布。
