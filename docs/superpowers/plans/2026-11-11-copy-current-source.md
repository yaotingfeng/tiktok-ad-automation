# 按当前广告事实复制 Implementation Plan

> **For agentic workers:** 在当前会话顺序实施并做一次独立最终复核；按用户授权直接推进，不增加原型确认流程。

**Goal:** 来源是否由本系统搭建不再影响可复制性；广告收入价值、目标ROAS与出价值分别展示。

**Architecture:** 复制来源只依赖当前授权目录。复制预览与原执行器共用冻结、幂等、回读链路，但策略/版权方/剧目/文案库关联为可选；平台素材由有界只读任务自动登记真实元数据后复用素材分发，禁止虚构版权方、素材大小或内容摘要。场景资格按实际Mini与目标账户核实。

**Tech Stack:** FastAPI/SQLModel/PostgreSQL/Redis/Celery、官方Python SDK、React/TanStack/shadcn。

**Spec:** 本次用户明确要求“不管是不是在系统搭建的，都应该可以复制”，取代2026-11-10复制设计中必须存在历史搭建关联的限制。

## Global Constraints

- 保留现有租户/BC/冻结连接权限、逐源逐目标份次、源变化检测和未知写入防重。
- 不创建虚拟版权方、策略、剧目或文案以满足外键；不以名称猜素材身份。
- 开发不创建真实广告；提交具体预览仍为唯一广告创建入口。
- 保留用户与其他任务改动，不创建或切换分支；完成验证后聚焦提交，未获明确请求不推送。

## Review Focus

- 无ExecutionStep来源必须可生成完整复制预览并进入已有执行编译。
- 平台返回的零预算、不限模式、自动年龄展开和只读字段不能误拦截；真正不支持的设置定位到字段。
- 读取来源失败不能显示默认最高价值或0条素材冒充事实。
- 素材元数据与CTA从来源当前账户读取；跨账户不能直接套用源VID、封面或资产。
- 旧复制草稿/已冻结预览保持不可变；新合同版本明确区分，普通搭建保持必填关联。
