# 自动规则素材口径：单账户 / 同一视频跨账户

> 已由同日用户确认的[广告内素材规则修复](2026-10-17-ad-material-rule-fix.md)替代 EACH 口径。下文为历史设计；不再按账户主素材合计后关停全部使用，也不将现有同步限制视为平台无法拆分的结论。

## 背景

素材层级规则此前只按「账户 + 主素材」判断，素材报表却按视频跨账户合计，两处口径不一致；
另外「按广告判断、执行到素材」时，会把命中素材在本账户所有广告里的使用一起暂停，超出了命中广告。

- Spark 广告每条广告单独发布帖子，主素材 ID 即帖子 ID，「账户 + 主素材」已等于「单条广告内的素材」。
- 非 Spark 的 Smart+ 广告主素材可能被同账户多条广告共用；素材日报不带广告，无法再按广告拆分，
  因此不单独提供「单条广告」口径，单账户口径保持合计并关停本账户内全部使用。

## 改动

1. 统计口径新增 `VIDEO`（同一视频跨账户合计），只用于素材层级；素材层级可选 `EACH`、`VIDEO`。
   - 视频归属复用报表的 `post_video_map`，与素材报表按视频合并的口径一致；对不上视频的素材不参与，计入跳过数。
   - 按（视频、币种）分组，不跨币种相加；执行层级只能是素材，执行对象为该视频在范围内各账户的素材。
   - 跨账户合计沿用规则时区运行的限制。
2. 按广告（或系列、广告组）判断、执行到素材时，素材目标只保留命中广告中的使用；
   同一运行内多个命中指向同一素材时合并使用位置。
3. 前端规则编辑器：素材层级显示「每个素材（单账户内）」「同一视频跨账户合计」，其他层级不显示视频口径。

## 验收

- 后端：口径校验、视频分组与跳过、多币种分组、执行目标展开、广告判断执行到素材只关命中广告的单测通过；
  `bash scripts/lint.sh` 通过。
- 前端：`bun run lint`、构建通过。
