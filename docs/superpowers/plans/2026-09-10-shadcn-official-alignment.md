# shadcn 官方工作台视觉统一

状态：2026-09-10 用户已确认方案，开始实施。

本计划替代 2026-09-08 原型中蓝灰主题、216px 侧栏、25px 页面标题和1536px内容限宽的视觉规定。业务与权限契约沿用原功能设计。

## 已确认的设计

- 参考 https://ui.shadcn.com/view/new-york-v4/dashboard-01 ，使用现有 Radix / New York 组件，采用 Neutral 主题与白色 inset 主面板，侧栏288px并支持图标收起。
- 页面名称进入顶栏，16px/24px、中等字重；正文说明14px，分组标题16px；不重复渲染大号页面标题。
- 列表与预览占满可用宽度，边距小屏16px、桌面24px，移除全局1536px限宽。表单按阅读需要独立限宽。
- 列表结构统一为工具栏、单层边框表格、分页；不在表格外再叠卡片。搜索输入约280–320px，窄屏自动换行。
- 表格14px正文/表头，取消表头大写及额外字距，恢复官方单元格8px内边距。信息和表单Card保留标准24px内边距。
- 现有1024px移动导航断点、租户/BC切换、权限提示、表格滚动与固定列继续适用；标题保留可访问的h1语义。

## 实施与验证

1. Root：共享标题挂载、WorkspaceShell、侧栏、主题tokens、Table/ServerTable/Pager及通用页面。
2. 管理列表worker：账户、版权方、素材、策略、租户与成员页组合。
3. 搭建worker：搭建输入、准备、预览、任务列表/详情及局部表格。
4. Root整合并独立审查；构建与既有workspace浏览器回归，补充宽屏/窄屏、侧栏状态和表格容器的验收。
5. 在真实本地应用8011构建并查看策略、管理、空状态；功能丰富的场景用既有API边界fixtures验收。此轮不调用真实广告/版权方/R2写接口。
6. 提交代码，快进同步运行目录与远端分支，记录测试和可访问地址。

验收尺寸至少390、1024、1440、2304px；展开/收起侧栏后内容边距稳定，无整页横向溢出；宽表在自己的容器内滚动；标题在导航后正确更新且唯一。
