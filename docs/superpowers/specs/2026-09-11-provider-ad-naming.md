# 版权方命名模板与短随机批次号

用户要求：普通版权方默认“版权方拼音-剧名-剧目 ID-随机号”，可通过变量配置；网眼等有专用规则的版权方优先使用专用规则；不再把 32 位 UUID 用作新广告名称中的随机号。

- 策略新增 `campaign_name_template`，默认 `{provider_pinyin}-{drama_name}-{drama_id}-{random}`。变量按钮分别插入版权方拼音、剧名、版权方剧目 ID、随机号、日期 `{YYYYMMDD}`。必须包含剧目 ID 和随机号，避免同批次同名剧被模板合并。
- `provider_pinyin` 取版权方集成的规范标识（当前 `jiashu`、`wangyan`）；`drama_id` 取版权方的 `external_drama_id`，不使用本地 UUID。
- 存在已核验的 `protected_base` 时，继续使用该基础名和既有 `campaign_suffix`。网眼归因前缀不可被通用模板覆盖；保留特殊规则后缀的日期和批次号变量。
- 广告组继续追加 `-g01`、`-g02`；广告追加 `-sp1`、`-sp2`。默认命名不包含日期，日期可在通用模板中自行插入。
- 每个新预览分配 12 位数字批次号，通过已有全库唯一约束和最多 10 次冲突重试保证已提交记录不重号。耗尽重试明确报错，不提交重复编号。相同预览的恢复和相同批次不同账户共用该编号；完整广告名称的唯一范围仍是广告账户。
- 预览新增版权方标识、外部剧目 ID 的快照列。新增迁移仅加列，不修改历史策略、已冻结名称、已提交请求或摘要。旧版仍在 BUILDING 的预览应明确失效并提示修改草稿后重建，避免新旧命名混用。
- 历史策略 JSON 缺少新增字段时采用该字段的默认配置；不增加旧通用命名引擎或旧字段别名。历史已冻结广告直接读取已保存名称。
- 前端保留 USD 禁用选择、黑色主按钮与 shadcn/ui；命名示例同时展示普通版权方和专用规则，示例使用 12 位数字。
- 发布须按环境手册冻结写入、排空任务、备份、迁移与验收；本轮先本地实现、验证和提交，未授权的新外部广告操作不执行。
