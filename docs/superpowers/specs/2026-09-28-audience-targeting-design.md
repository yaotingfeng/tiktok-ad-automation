# 策略默认定向与搭建时地区核验

日期：2026-09-28

状态：用户已确认产品流程及严格限制语义，尚未实施；进一步明确国家选项必须来自 TikTok 实际开放范围，不能使用全球国家全集。

## 目标与已确认范围

用户希望在策略中提前选择国家、语言、年龄、性别；搭建时根据广告账户和所选小程序核验可投国家，允许仅修改本次批次，并在提交前看到最终定向。

- 策略保存投放意愿，不宣称任意账户和小程序均可投。
- 搭建准备页在小程序选择之后提供「受众定向」卡片。
- 同一批次使用统一定向，不增加逐剧或逐广告组覆盖。
- 多账户指定地区选择器展示共同可投国家，可查看账户差异。
- 不支持的已选国家保留并标红，要求用户调整；不自动删除或扩大定向。
- 更换国家不自动选择语言，剧目语言不自动成为人群语言。
- 保存本次配置不创建策略版本；更新策略仍通过已有策略保存入口。
- 不增加兴趣、行为、人群包、设备定向。

## 当前代码与数据来源

1. `integrations/tiktok/read_normalization.py` 从 Minis 列表记录的 `region_codes` 解析小程序支持地区；地区接口结果必须具有 `COUNTRY`、`ADMIN` 以及有效的国家代码与 `location_id` 映射。
2. `modules/builds/scene.py::_assemble_scene` 将小程序支持地区与当前账户场景地区列表求交集，全部写入 `targeting_spec.location_ids`，并保存 `field_constraints.target_regions`。
3. `modules/builds/request_compiler.py::_Targeting` 仅接受地区 ID；`contracts/builds.py::AdGroupObservedFacts` 尚无语言、年龄、性别及定向模式。
4. `StrategyConfig`、草稿请求与 `BuildDraft` 尚无用户定向字段。预览已有冻结 `config` 与逐组合 `scene_snapshot`，可扩展复用。
5. API 和 MCP 创建均经过 `create_arguments`；回读经过 `readback_compare.py`。新增字段必须贯通这些共同边界。
6. 地区查询中的 `language="en"` 仅影响目录语言，不是广告语言定向。

## 交互

### 策略编辑

复用现有 shadcn/ui Card、Field、Select、Checkbox、搜索输入及多选展示。

| 字段 | 控件与语义 |
| --- | --- |
| 国家/地区 | 全部共同可投地区 / 指定国家。指定国家支持搜索、多选、全选和清空。策略里的目录是参考目录，不标记为当前可投。 |
| 语言 | 不主动限制 / 指定语言。指定语言使用已核实的平台代码目录，不能把任意 ISO 代码视为有效 TikTok 参数。 |
| 年龄 | 不主动限制 / 指定年龄段。仅展示当前合同支持的分档，不接受任意最小最大年龄输入。 |
| 性别 | 不主动限制 / 男 / 女。 |

「不主动限制」表示工具不增加该维度的限制，不承诺绕过平台或账户自身约束。默认不隐式新增 18+ 条件。

国家目录必须来自官方地区接口的有效同步证据，不能使用全球 ISO 国家全集或人工写死的国家白名单：

- 策略页参考目录：仅汇总当前明确选择的 BC 中，已获授权且有有效 Minis 场景证据的账户/小程序可投国家（并集），显示为「可预设，搭建时核验」。这不是任意账户的可投保证，也不是 TikTok 全球完整开放名单。
- 没有 BC 上下文或有效目录时：提示选择 BC 并完成账户/小程序地区同步；不从其他 BC 借目录，不以全球名单补齐。仍可保存「全部共同可投地区」。
- 搭建页：使用本批所选账户与小程序的可投国家交集，作为本次真正允许选择的范围。
- 旧策略里的已选国家即使不再出现在目录中，也保留标签并标记待核实/不可用，不静默清除。

年龄、语言、性别的具体选项须先通过当前平台合同核实。

### 搭建准备

卡片位于小程序选择器之后，展示来源「策略默认」或「本次已修改」，提供「修改本次定向」和「恢复策略默认」。

卡片状态：

- 未选择账户/小程序：提示完成前置选择，不能宣称国家列表已经核实。
- 地区准备中：显示已核实账户数量与待核实数量，已有选择保留。
- 地区准备完成：显示共同可投国家，允许从中多选。
- 无共同国家：明确提示分开搭建或调整账户/小程序，阻止生成可提交预览。
- 已选国家失效：保留国家标签，显示缺少支持的账户数量，展开分页查看具体账户及原因。
- 缓存过期/授权变化：提示重新准备，不能降级为全部国家或沿用别的连接的目录。

例：策略选美国、加拿大，本次小程序与账户仅共同支持美国、英国。美国有效，加拿大标记不可用，英国是可选项但不会自动添加；用户移除加拿大后才可提交。

### 提交预览

显示共同的国家名称、语言、年龄、性别及最终定向模式。单账户明细同时显示实际发送的地区与核实状态，不要求用户阅读 JSON 才能确认。

策略或草稿改变后，已有预览按 revision 机制失效；已提交任务继续使用原冻结配置。

## 数据合同

采用独立且严格的 `AudienceTargeting` 模型，禁止任意附加字段：

- `region_mode`: `ALL_AVAILABLE` / `SELECTED`。
- `region_codes`: 去重、规范排序的国家代码；`SELECTED` 必须非空，`ALL_AVAILABLE` 不允许带选择列表。
- `languages`: 可空的平台语言代码集合；空集合代表不增加工具侧限制。
- `age_groups`: 可空的平台年龄枚举集合；空集合代表不增加工具侧限制。
- `gender`: 不主动限制 / 平台男性枚举 / 平台女性枚举。

用户选择使用国家代码，账户执行使用由当前场景解析的 `location_id`；不在策略中保存跨账户地区 ID。

策略版本新增 `targeting`；草稿新增 nullable JSONB `targeting_override`：

- `null`：继承草稿所引用的不可变策略版本。
- 对象：本次完整覆盖，避免逐字段继承引入难解释的组合。
- PATCH 字段遗漏：保持原覆盖；显式 `null`：恢复策略默认。
- 更换策略：继承状态跟随新版本，已有显式覆盖保留，并在页面标明。

新增模型同时进入策略差异比较、复制策略、保存幂等摘要、草稿恢复和生成客户端，不能只修改表单。

## 地区范围与扩展性

对账户 a 和本批所选小程序 m：

`eligible(a, m) = minis_region_codes(a, m) ∩ region_tool_codes(a)`

`common = 所有所选账户 eligible(a, m) 的交集`

统一定向的 `ALL_AVAILABLE` 明确解析为 `common`，不是每个账户分别选择自己的全部国家。与当前按账户自动全选相比，这是需要在新预览中明确展示的行为变化。

目录读取复用当前租户、BC、连接、授权代数、小程序及场景证据的边界，不跨 BC 或连接复用。所有账户均完成有效核实后，才能把交集标为可用；未知账户不能从分母中删除。

新增草稿定向目录只读接口，返回：草稿 revision、小程序 ID、账户总数、已核实数、共同国家、用户选择中的不可用国家及原因摘要。账户差异通过分页接口读取。

实现应基于当前准备任务的账户依赖及有效场景证据进行数据库集合聚合，或复用后台有界分页准备过程生成聚合结果；禁止 GET 循环调用 TikTok、禁止请求内无界逐账户读取。10 万账户场景下交集状态至多保留国家集合和计数，不把整个账户矩阵装进返回值。

目录结果只是选择辅助；生成预览时必须按当前 revision、连接、授权代数和有效场景证据再校验，不能信任前端提交的可投列表。

## Smart+ 模式与平台合同核实

当前项目 MCP 工具合同具有 `targeting_optimization_mode`（`AUTOMATIC` / `MANUAL`）、`suggestion_audience_enabled` 及年龄、语言、性别字段。官方 SDK 文档也暴露相应属性，但「属性存在」不证明所有 Minis 场景都允许该组合。

在发送实现前完成合同核实：

1. 确认 Minis、VALUE、所选优化事件下可使用的定向模式及组合限制。
2. 核实语言代码目录、年龄枚举、空值/省略的具体语义。
3. 确认创建及查询接口对模式和新增字段的可观察性。
4. 对 API 与 MCP 使用同一个业务合同，并验证对应适配器均支持；不自动切换连接。

用户已确认严格限制：按核实后的手动/控制合同发送，接口不支持时阻止提交，不变成受众建议。本次不实现受众建议模式。严格限制指请求设置及模式遵守用户选择，不承诺平台推断的用户年龄、语言、位置等信号绝对准确。

本设计不凭字段名称猜测模式，也不通过创建真实广告探测支持程度。开发测试使用官方传输边界替身；真实业务验收需另有具体广告操作授权。

## 保存、冻结、执行与回读

1. 草稿覆盖保存复用行锁、expected_revision 与幂等请求记录，避免另设无保护写入口。
2. 仅修改定向应保留已准备的剧目、手动素材分组及账户，不走会删除 DraftGroupMaterial 的通用输入重建分支；复用现有准备机制核实所需场景。
3. 预览冻结有效定向、共同国家及各账户实际映射，纳入内容摘要。不得在执行时重新读取策略默认值覆盖冻结请求。
4. 扩展 `AdGroupCreate`、`AdGroupObservedFacts`、编码/解码器和回读投影，集中生成 `targeting_spec`。
5. 年龄、语言、国家等集合按集合语义规范化比较，平台返回顺序不同不构成冲突。
6. 平台缺少已请求的字段时保留待核实；不以发送值填充观测值。实际值不一致时沿用现有差异处理，不自动放宽条件。
7. 旧冻结任务及历史请求保持原字节语义；新配置只影响新生成的预览，不改写历史记录来伪造已设置语言或年龄。

## 迁移与验证边界

- 使用新增 Alembic 迁移添加草稿覆盖列；策略配置采用明确的数据升级方案，历史冻结快照不回填新增投放事实。
- 本地专用测试数据库执行迁移验证。测试/生产部署继续遵循备份和发布手册，本次设计不代表服务器变更授权。
- 不新增自动广告写入；现有具体预览提交后的执行流程保持不变。

## 实施分段与验收

### 第一段：模型和地区核验

策略与草稿合同、迁移、可投范围聚合、分页差异、仅定向修改的 revision/幂等处理。

验收：多账户交集正确；未知/过期/跨 BC 证据不能产生可用范围；指定国家失效不被自动删除；覆盖恢复、换策略、冲突重试均符合语义；保留手工素材分组。

### 第二段：冻结与平台链路

按用户确定的模式贯通场景校验、冻结请求、SDK/MCP 编译、回读比较与差异展示。

验收：两通道发送相同业务定向；省略、空值、不支持组合严格区分；缺字段与不同顺序回读分别正确处理；修改草稿不能改变已提交任务。

### 第三段：页面与整体验证

策略表单、搭建定向卡片、搜索多选、账户差异、预览摘要、客户端再生成。

验收：前端真实交互测试覆盖保存、恢复、国家失效和只读角色；后端行为测试覆盖上述合同；类型检查、前端构建、格式和差异检查通过。模拟通过不报告为真实 TikTok 业务验收。

## 2026-09-28 合同核实与实施落点

- [官方 Upgraded Smart+ Ad Group 创建合同](https://business-api.tiktok.com/portal/docs/create-an-upgraded-smart-ad-group/v1.3)明确：`MANUAL` 支持 location、languages、age_groups、gender；默认 `AUTOMATIC` 会忽略部分不兼容定向字段且不报错。本实现新预览显式发送 `targeting_optimization_mode=MANUAL`，不发送仅适用于 AUTOMATIC 的 `suggestion_audience_enabled`。
- `AGE_13_17` 仅适用于 APP_INSTALL/APP_RETARGETING；本工具 Minis 仅提供五档成年年龄。语言使用[官方 Language Code 枚举](https://business-api.tiktok.com/portal/docs?id=1737174886619138#item-link-Language%20Code)的 41 项代码。语言/年龄不选时省略对应字段，性别默认 GENDER_UNLIMITED；平台自身限制仍生效。
- 策略国家参考目录从当前明确 BC 的默认连接内、当前授权代数和绑定代数下的未过期完整场景聚合；搭建使用该草稿固定连接、所选小程序及全部所选账户交集。地区 ID 逐账户解析。参考目录不代表某个具体 Minis 在全部账户均可投，最终以预览核实为准。
- 授权证明缺失、未来时间戳、撤权、过期场景或最新场景未完成不计作已核实，保留批次全部账户分母；已核实但没有交集返回不可用。目录读取仅访问本地证据，重新核实复用已有后台准备流程。
- 旧策略 JSON 不回写，读取时按新的明确默认配置解析；旧冻结预览及已提交请求不改写。升级时仍在 BUILDING 且缺少定向冻结信息的预览明确失败，须重新生成。
- 执行前把当前场景按**冻结选择**重新投影后比较，新增可投国家不会扩展冻结国家范围；缺少所选国家阻止发送。SDK/MCP 编译和回读共用同一定向合同。
- 本次为本地实现与离线传输边界验证；未创建真实广告，未验证具体账户实际投放结果，未部署服务器。
