# 外部素材批量推送

用户已在会话确认并授权实施。交付本地实现、迁移、接口文档与测试，不包含推送或部署。

## 契约

- POST `/api/integrations/materials/batches`，JSON 为 `tenant_name` 和 1–200 条 `materials`，每条仅必填 `material_id`、`file_name`、`url`。禁止多租户、重复素材 ID、未知字段；名称精确匹配已启用租户，重名拒绝。文件名带视频扩展名并完全保留。
- HTTPS + HMAC-SHA256；请求头 `X-Key-Id`、`X-Timestamp`（Unix 秒）、`X-Request-Id`（UUID）、`X-Signature`（sha256=小写 hex）。签名输入为 method、path、timestamp、request_id、SHA256(raw_body) 五行，无末尾换行。时间误差最多 300 秒，恒定时间比较，最大请求体 2 MiB。GET 相同验签，body 为空。
- 系统管理员在私有配置中设置接入密钥、执行用户、允许租户 ID 和来源 HTTPS 主机；运营不接触密钥。执行用户必须是目标租户的有效上传成员，后台每次重新核实权限。密钥和完整签名 URL 不进入日志、outbox、响应。
- 按 `(key_id, request_id)` 持久幂等，相同原始请求体返回原批次，不重新解析默认 BC；内容不同报 409。每次重试用新时间戳签名。批次固定实际租户、BC、操作者、连接与授权代数。
- 目标为租户配置的默认 BC，否则按现有目录 `bc_id` 升序第一条。所选 BC 无合法上传权限时报错，不另选；使用其默认连接、主素材账户。平台管理员可在租户编辑中设定/清除默认 BC。
- GET `/api/integrations/materials/batches/{batch_id}` 返回逐项状态、内部素材 ID、实际账户、VID、错误码。202 仅代表接收；校验、上传、可用、失败和未知状态分开。

## 外部来源和更新

- 外部素材 ID 按租户唯一；同 ID 新请求登记新修订，旧批次重试不覆盖新修订。按接收顺序更新当前修订指针；旧任务完成不能抢回当前指针。
- 异步流式读取已有 R2 URL，限定大小、耗时、精确主机及公网 IP，禁止凭据、片段、非 HTTPS、自定义端口和重定向；DNS 解析后固定连接地址，TLS 按原主机核实。读取临时本地文件计算 SHA256/MD5并复用 ffprobe，完成后删除本地暂存。不写入另一 R2 桶。
- URL 加密存储；来源必须是处理期间稳定不覆盖的对象。链接失效逐项报错，可用新批次重推刷新。签名 URL 不要求支持 HEAD，GET 响应和实际字节校验大小。
- 同内容、同名且同目标 BC 的已可用内部版本可复用；同冻结连接的在途/未知上传同样沿用原任务，不重新发送。新 URL 读回同内容后由较新修订续期；内容或名称变化创建新内部素材，不覆盖既有广告引用、VID、上传操作。旧版本保留供历史投放使用。
- 新版本创建已校验的外部原件引用、入库会话，接入现有 source URL 上传/回执/核实/封面/分发。外部对象标识为 `external`，不占自有 R2 暂存预算，任何自动/手工清理与浏览器分片路径不得删除/写入外部对象。
- Worker 用短事务和租约领取单项；HTTP/媒体检查不持数据库锁。断点恢复沿持久 outbox 与周期修复，不重发结果未知的 TikTok 上传。

## 验收

真实本地 PostgreSQL/Redis；网络替身在 HTTP 边界。覆盖签名/时效/体积/跨租户、默认 BC/冻结连接、批量原子登记和逐项失败、幂等/并发/过期领取、同 ID 更新/历史保留、URL SSRF/重定向/大小/摘要/媒体校验、外部原件不可删除、现有 URL 上传与封面分发、租户默认 BC UI。迁移保留历史，不自动改名或清除数据；重名在迁移前明确拒绝。
