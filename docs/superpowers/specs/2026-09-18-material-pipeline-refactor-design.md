# 素材统一批量流水线

用户已批准：跨 BC 只做一次 URL 转存，之后与同 BC 库存共用共享实现；成功回执快速推进，固定来源、批量规划、服务器可承载的最大稳定并发；部署新加坡测试服。

## 执行契约

- 保留租户、内容摘要、账户授权、冻结连接/绑定代数和已确认广告内容；不得改写已发送请求或 SQL 补写成功状态。
- 跨 BC 每内容只转存到目标 BC 的主素材账户一次。取 URL 和上传在同一次领取中连续执行，不将短效 URL 入队或持久化；未发送退避后重新取 URL。
- 同 BC 原生素材与转存后的素材使用同一来源选择、矩形规划、共享、目标映射和异常恢复路径，不新增第二套共享实现。
- 成功上传回执的实际 VID 可以发布目标映射，缺 MID 时只在共享确需时补取。已有来源 URL 导入回执规则作为一致性参考，不伪造远端 MD5/状态。
- 已确认视频/封面映射不因本地 900 秒年龄自动失效；真实权限撤销、VID 改变、内容不匹配、平台明确不可用继续阻断。未知结果不自动重传。
- 按冻结素材集合规划最多 20 素材 × 10 账户的有界滚动窗口，先登记本次补入素材的全部账户需求，再发送；按在途唯一素材数补货，单个慢请求不阻塞剩余空槽。不为每个广告建立独立上传，不展开无限未来图。
- 保留准备、结果、搭建、控制隔离；使用 Linux prefork 硬期限。增加并发必须结合 2 核/2 GB 主机的实际内存、连接和吞吐证据，不能用无界线程/进程或去掉限流。
- 封面保留 IMAGE 类型参数差异，但复用现有共享能力；不按每个目标重制封面。

## 验收

真实 PG/Redis 测试覆盖成功回执免回读、缺 MID 补取、过期本地时间不触发刷新、跨 BC 首次转存唯一、20×10 准备/共享、并行幂等与权限隔离、UNKNOWN 不重发。实服先完整备份和独立恢复验证，再部署同版本全部服务，观察原批次推进和资源占用。平台拒绝/未知不得报告为成功；不承诺未经测量的完成时限。
