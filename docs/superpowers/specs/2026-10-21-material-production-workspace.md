# 素材制作内嵌工作区

用户要求把“素材制作”从直接跳转改为投放工具内创建任务、查看生产进度，并保留“打开素材工作台”按钮。按现有 Python/FastAPI + React 应用实现；Java 表述已请求澄清，默认不另建服务。

## 接口合同

依据用户本地 external-task-api(1).md：公司 owk_ 调用策略目录、平台账号、素材库能力、POST /api/schedules、GET /api/jobs 及 GET /api/jobs/{id}。开户/免密仍用原 owp_，浏览器不得获得公司 Key。所有请求按当前有效租户权限取已就绪绑定，不使用前端提供的公司/账号凭据。

支持素材库、常读、自有链接；手输剧名、策略、多剧、业务日期、飞书回写表格、备注及条件集数。常读另选一个有效常读账号和短剧/漫剧。素材库每次新建前查询能力，full_series_v2 不传集数字段。固定 self_download、unified-new-webui、intervalMinutes=0；成片回传保持素材侧原链路，不在此实现上传/下载/取消。

## 可靠性和页面

本地订单先保存不可变请求、订单 UUID、租户/操作者/公司、提交时间及 outbox；control 有界重试，始终同一幂等键和原始请求体。收到 job.id 后保存且不再重发。超时/崩溃可恢复，不因重试更换 startTime。业务错误停止自动重试并显示脱敏说明；不透传凭据/远端任意响应正文。

页面有新建任务表单、提交状态、按北京时间日期筛选的远端任务表及逐剧详情。远端进度每 30 秒查询，后台页不轮询；本地排队状态可更快刷新。日期列表最多 50 条，达到上限明确提示缩小范围，不能假称完整分页。任务结束要求 progressItems 非空且每项 succeeded/failed；queued/running/retry_waiting 仍继续查询，终态保留手动刷新。stage 仅展示；R2 delivery 展示数量和状态，不接管回传。

沿用现有 upload 权限（平台/租户管理员与投手），viewer 不显示页面入口且后端拒绝。页面、查询 key、订单、工作台按钮均按租户隔离；切租户丢弃旧请求结果。页面保持 shadcn 中性黑主按钮规范。junbo 上游既有账号冲突不伪造 ready，页面明确显示未开通原因。
