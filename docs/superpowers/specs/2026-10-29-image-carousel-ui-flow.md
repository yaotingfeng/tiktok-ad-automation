# 图片轮播搭建：界面与操作说明

> 2026-10-29。本文是拟新增功能的操作方案，尚未实现。保留现有搭建工作台，不新增独立的轮播管理主流程。业务规则见[批量搭建设计](2026-10-28-image-carousel-ads-design.md)。

## 1. 最短操作路径

素材库上传图片 → 新建搭建选择「图片」→ 输入剧目、账户和策略 →「解析并准备」→ 设置整批规则 →「查看生成结果」→「应用并生成」→ 处理少量异常 →「生成搭建预览」→ 核对后提交。

正常情况下，只设置一次规则，系统为每部剧分别生成轮播并配乐；不需要逐个新建轮播。

## 2. 上传与批量输入

**当前既有：** 素材库批量上传入口；搭建页的版权方、策略、剧目、广告账户，以及「解析并准备」按钮。

**拟新增：** 素材库支持手动批量上传图片；搭建输入页增加「投放素材类型：视频 / 图片」，默认视频。

1. 在素材库一次选择多张图片上传，文件名包含完整剧名，方便自动匹配。
2. 回到搭建输入页，选择「图片」，填写剧目、目标账户并选择投放策略。
3. 点击「解析并准备」，进入现有第二步「准备与调整」。全部剧目面向本批全部有效账户。

一份草稿只选视频或图片；需要两种投放时分别建两批。已有编排后，使用「以另一类型新建草稿」，不覆盖当前结果。

## 3. 第二步：设置整批规则

**当前既有：** 「准备与调整」页面、「剧目与素材」表格、账户解析及页面底部「生成搭建预览」。

**拟新增位置：** 在「剧目与素材」表格上方放置「整批图片规则」卡。现有小程序、定向、身份和排期区域继续保留。

| 设置 | 用户看到的选项 |
|---|---|
| 图片组合 | 单图 / 顺序轮播；默认顺序轮播 |
| 每轮播张数 | 默认 3，可选 2–35；单图模式每个创意 1 张 |
| 图片排序 | 自然文件名 / 上传顺序；默认自然文件名 |
| 尾部不足张数 | 保留 / 本次不使用；默认保留 |
| 配乐方式 | 按轮播推荐 / 整批指定一首 |
| 单图用曲 | 推荐模式下可选；实际有单图时需要配置 |

卡片中的「本次广告结构」可展开：默认继承已选策略，需要时仅调整本次整批。每轮播张数决定图片怎么组合，不等于广告数；最终广告数和预算以搭建预览为准。

修改规则后显示「有规则尚未应用」，已有轮播保持原样。点击 **「查看生成结果」** 打开差异面板，不直接生成或替换。

## 4. 差异面板：确认怎么生成

**拟新增：** 面板按剧列出将新增、保留、替换的轮播，以及本次不使用的图片、待配乐项和预计广告变化。

例如，一部剧有 13 张图片，按自然文件名排序，每轮播 3 张，尾部保留：生成 **4 个三图轮播 + 1 个单图创意**。另一部剧单独排序和分组，不会混入这部剧的图片。

- 默认保留手动调整，面板明确显示哪些内容会保留。
- 需要覆盖时，显式选择「同时替换手工调整」，先查看将失去的修改。
- 点击「返回修改」或关闭面板：不改变已有轮播。
- 点击 **「应用并生成」**：一次为本批各剧生成轮播，随后自动准备音乐；此操作不创建广告。

回到原页面查看「生成中」「配乐中」「待处理」「已就绪」进度。可以离开后再回来继续查看，无需保持页面打开。

## 5. 按剧查看与手工调整

**当前既有：** 剧目行有「查看与调整素材」，打开素材侧栏；当前侧栏是文件列表与组号编辑。

**图片草稿拟新增：** 剧目行提供 **「本剧规则」** 和 **「查看与调整轮播」**。侧栏显示有序缩略图、张数、曲名、配乐状态及手动保护标记。

| 入口或动作 | 操作与生效时机 |
|---|---|
| 本剧规则 | 只覆盖所选字段；「恢复整批配置」清除覆盖。仍需查看生成结果并应用 |
| 编辑图片 | 在卡片编辑器内增删图片、拖动排序；点击 **「保存图片调整」** 才写入，取消则保留原内容 |
| 换音乐 | 搜索、试听并选择曲目；点击 **「使用这首音乐」** 才写入，关闭选择器不换曲 |
| 更多：复制、合并、拆分、删除 | 先展示影响，点击对应确认按钮才生效；删除时说明相关图片本次不再自动使用 |
| 侧栏底部「完成」 | 只关闭侧栏，不代替保存；有未保存图片编辑时提示「继续编辑」或「放弃未保存调整」 |

保存图片调整后，已有音乐保留，并提示「图片已变，可重新推荐」；不会自动换曲。复制继承原曲；合并、拆分后的新创意进入待配乐，有音乐保护冲突时先提示处理。

手动保存图片内容或顺序后标记 **「图片已保护」**；手动选曲后标记 **「音乐已保护」**。两种保护分别显示、分别解除。重新生成默认保留保护项；解除保护本身不会立即重生成。

## 6. 待配乐与其他问题怎么处理

**拟新增：** 逐剧表上方提供「待配乐」「有未使用图片」「有手动调整」筛选；问题数量旁有「去处理」。

上面的 13 张图片例子中，若未指定单图用曲，最后 1 个单图显示「待选音乐」。点击「去处理」直接定位该卡片，选择音乐并点「使用这首音乐」；也可在整批规则中指定单图用曲，再查看并应用变化。

推荐失败可「重试失败配乐」或手动选曲。若准备阶段失败、部分单元尚未启动，恢复权限后勾选对应剧目，使用「重试所选剧失败配乐」补接；确认弹窗说明也会处理这类未启动项，包括复制时继承“处理中”但尚未关联任务的轮播，保留手工音乐与已有任务。明确重试时不复用旧的失败结果；原任务仍在运行或已有成功结果时继续复用，重复重试不重启已关联任务。准备期间可以查看、调整和保存草稿；尚有待配乐、未应用规则或未处理冲突时，底部「生成搭建预览」不可用，并显示具体原因及「去处理」。

## 7. 区分刷新、重新匹配与重新生成

| 按钮 | 是否改变已应用轮播 |
|---|---|
| 刷新准备结果（既有） | 只读取最新进度，不重新匹配图片或重做轮播 |
| 刷新匹配图片（拟新增） | 重新查找候选图片，展示新增/移除差异；等待用户应用，不自动加入晚上传图片 |
| 查看生成结果（拟新增；首次生成和重新生成共用） | 按当前规则展示差异；只有再点「应用并生成」才更新轮播，默认保留手动保护 |

## 8. 进入搭建预览

**当前既有：** 页面底部「生成搭建预览」及后续具体预览、提交流程。

**拟新增内容：** 预览能查看每条广告中的完整轮播、图片顺序、曲目及不可用原因。核对账户、广告数量和预算后再提交；规则生成、手工保存和音乐选择都不等于投放提交。
