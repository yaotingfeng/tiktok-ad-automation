# 账户报表成员版本与日汇总

用户已要求实施前述成员预存与日汇总方案。本轮原位main开发，不推送/部署其他未发布功能，不更改金额与冻结选择合同。

## 存储与原子性

- `account_membership_version`：不可变的tenant/advertiser、系列refs与逐系列名称版本；UUID主键。只允许退休时间变更。
- `account_membership_current`：每账户一个版本指针。账户创建保证空版本；目录campaign或名称投影写入后，在原事务内按账户排序锁指针、重算并比较payload，内容不变不建版本。旧版本退休后至少一小时且没有当前指针/查询快照引用才可回收。
- `query_snapshot_row.account_membership_version_id`：账户行必须引用版本，refs不再存复制；其他维度不引用。首屏只展开当前页，选择/导出展开原版本及原名称版本，不查当前目录；导出仍复制完整成员以脱离15分钟快照。
- `account_report_day`：账户/当地日/币种/时区的SUM和逐指标has_null。来源为已有campaign_report_day，与发布同事务维护，保留已有系列层严格NULL及账户部分合计口径。
- `account_report_day_state`：每账户日的汇总写锁/修订和ad_day覆盖状态镜像。先更新锁行，再重建汇总；并发RR旧读者必须序列化失败，不能覆盖更新。report_sync_state的ad_day状态同事务镜像，其他报表种类不影响。

## 读取

默认账户快照读日汇总、状态镜像与当前成员UUID；没有逐系列遍历或全候选名称展开。需要版权方文字/命名条件时仍读取该条件要求的事实元数据。分页、ALL_MATCHING/EXPLICIT、导出保留原排序与原成员，权限每次由现有tenant/BC/actor授权校验。

快照头名称版本用成员版本UUID表示不可变来源；在选择/导出边界展开成原逐系列版本映射。直接ordered_members调用仍展开refs，正常快照构建不展开。

## 迁移

0103接在当前0102之后，新增表/索引/字段/固定SQL触发器，冻结写入时回填所有存活账户版本，并以集合SQL回填账户日金额/覆盖。0081保留的已删除账户canonical金额和状态不进入派生表，也不删除；重新发现账户时，INSERT transition触发器按新账户集合恢复历史日金额和覆盖，目录成员只来自当前canonical目录。既有账户查询快照根据其已冻结refs和名称版本转换，不能改成当前成员。已有冻结选择/导出不变。程序和数据库一同前向切换；降级先展开版本回原快照refs和名称版本，再删除新对象，保留所有源事实。真实生产当前0101，不能未经范围确认将本地0102一起发布。

真实PG测试增删/改名/空账户、更新不变去重、跨租户/BC撤权、快照后新增/删除/改名、导出独立存活、TTL回收、事务回滚/RR并发、任意NULL/跨日/多币种/完整空桶与状态变化；旧快照迁移和降级往返。大样本证明首屏不扫描ad_entity_read/campaign_name_current，账户金额只读账户日行，结果与源事实等价。无真实广告写入，无未批准生产DDL。
