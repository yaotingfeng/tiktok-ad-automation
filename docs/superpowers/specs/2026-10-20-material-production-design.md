# 素材工具联合开户与免密进入

## 已确认范围

用户授权制定计划并立即开发：新建租户时同步开通素材公司，保存开户结果；菜单增加“素材制作”，通过最新文档 6.10 的免密链接进入。成片回传不在本次范围。依据 2026-10-20《短剧剪辑任务接口接入指南》6.9、6.10。

## 开户与身份

默认采用新建租户时同时新建专属投放管理员，填写租户显示名称、登录账号、初始密码。公司名对应租户名，两边登录账号及初始密码相同。显示名允许中文，登录账号遵守现有 Username 规则，避免静默转拼音。用户已获询问，可在开发中调整这一入口选择。

本地租户、用户、管理员成员、外部开户记录和 outbox 在同一事务写入。接口使用客户端操作 UUID 防重复创建，重复请求须内容一致。外部请求固定 r2/true，以持久操作 ID 生成 Idempotency-Key。外部开户通过 control 队列执行，数据库行锁串行化同一绑定；网络失败有界退避重试，明确业务错误停止并展示。恢复扫描重新投递丢失执行，成功记录绝不重放（上游重放会轮换公司 Key）。

待开户请求含密码，按租户加密保存，仅用于原样重试，成功后清空；本地登录仅保存哈希。保存外部 company/user/username、加密公司 API Key、开户密钥配置引用及指纹、状态、脱敏错误、时间。密钥原文只在私有运行配置，原始响应与密码不进日志或 outbox。

## 免密登录

POST /api/tenants/{tenant_id}/material-production/login-link 无用户名参数。校验当前有效租户及 upload 权限（平台/租户管理员、operator），按绑定记录和原开户密钥向 POST /api/provisioning/login-links 提交唯一 username。只接受素材工具同源固定 consume 路径、单个非空 token、未过期响应；不跟随 HTTP 重定向，不消费链接。返回 no-store 响应，仅当用户明确点击时申请。

侧栏“素材制作”为动作按钮，点击后直接跳转；失败停留原页显示错误。无有效租户或 viewer 不展示。成功前/失败时可在平台租户详情查看状态与重试；旧租户显示未开通，不擅自为历史数据创建外部公司。

## 配置与验证

使用 MATERIAL_TOOL_PROVISIONING_KEYS（配置引用到 owp_ 密钥映射）、MATERIAL_TOOL_DEFAULT_KEY_REF。不增加业务布尔开关。缺少配置阻止联合开户，现有其他业务照常。密钥指纹变化阻止错用另一把密钥；轮换与存量账号迁移需要服务方确认。

数据库迁移、本地 PostgreSQL 行锁/恢复测试、HTTP 传输替身测试、前端浏览器测试与构建必须通过。真实开户/免密联调与部署分开，缺少有效密钥时不得宣称已联调。停用 TK-ADA 账号只阻止新链接，素材侧已有七天会话撤销不在本接口能力内。
