# 批量复制系列

用户已确认 `outputs/unclassified/20261110-copy-prototype/aligned-bulk-copy.html` 原型并于2026-11-10授权实施。一次在当前租户、当前BC的系列列表中选择来源，进入独立配置页；一行一条来源。版权方、推广应用、小程序、链接、身份、广告组/广告归属、实际文案分别继承。

ROAS、预算和每账户份数行内编辑。账户复用AccountPicker的搜索、列表、多选；定向复用TargetingForm，排期复用DraftSchedule，素材使用侧栏与明确保存/取消。勾选只用于批量填值；提交范围为队列内全部来源。没有手填文案、没有文案重新抽样。保持现有shadcn与中性主按钮。

比较方案：统一参数弹窗不能逐系列调参；直接复用普通搭建草稿会因单版权方/应用和单策略配置丢失各系列差异；采用独立复制草稿/行配置、按来源独立子预览、复用现有冻结搭建执行与任务页。

复制的来源事实与历史关联分离：当前AdObject层级及configuration决定可创建设置；历史ExecutionStep、BuildUnit仅恢复经过验证的版权方、剧目、链接与本地素材关联，不能覆盖当前缺失配置。严格检查字段完整、平台类型、素材集合及父子身份。当前创建通道不能表示的普通/旧Smart+、缺少必要事实/推广链路/素材映射、无法无损继承的设置在行内阻断；不偷偷改结构、借用其他版权方/账户资产或把历史值冒充当前值。

复制合同独立于目标场景资格证据。新子预览使用独立的draft/preview/route与固定复制意图，原执行器依次准备素材、CTA、系列、组、广告并回读；只在明确复制分支编译当前设置与授权覆盖，不改变普通搭建。预算/ROAS覆盖一次计算冻结。份数不重用源系列，所有副本生成新身份与可追溯名称。

复制草稿持久化、修订号防并发覆盖；create/save/preview/submit使用请求幂等键及内容摘要。preview后台有界生成，冻结子预览清单与摘要；submit只能提交同一修订冻结结果。后台与提交重新检查租户/BC/成员权限、源/目标账户、连接与绑定代数。重复投递和未知平台结果复用原执行器恢复，不重复创建。父批次聚合已有搭建任务并提供链接。

最大100条来源、每源100目标、每账户1–20份，展开最多1000个新系列；超限明确拒绝。目标币种不同不换算，按币种展示汇总，不能把跨币种统一预算视作同值。用户更改目标时需重新核验场景/小程序与素材；原VID不能跨账户直接套用。

开发不调用真实广告或版权方写操作，不推送、不发布。新增迁移和持久化任务合同需要单独选发布方案。测试用独立真实PostgreSQL/Redis，平台只在传输边界替身。
