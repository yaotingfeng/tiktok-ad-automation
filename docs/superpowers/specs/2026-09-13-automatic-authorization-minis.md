# 自动授权权限与搭建小程序选择

用户已确认：授权接入自动完成权限同步并缓存；取消版权方应用手填 Mini ID 的搭建前提，可信链接自动匹配，否则按名称选择并复用。延续已授权的测试部署，无新增功能开关。

## 权限

API/MCP 完整目录已读取授权范围和 ROLES 页；发布时直接复用这些真实页构造账户能力缓存并批量发布权限，不再丢弃后要求第二次远端重检。未知 scope/角色不授予写权，明确 Analyst/停用/失权仍受限。过期或撤权走现有自动刷新与冻结版本校验，逐素材只做本地授权检查。

## 小程序

小程序列表是广告账户资产；场景缓存按冻结账户授权与 Mini ID 复用，取消以版权方应用映射为选取来源。无选取时只读取 Mini 目录，展示名称；不能把唯一候选、同名或短链接码当作已知对应关系。明确 TikTok 链接标识可自动匹配，否则用户在搭建页面选择本批次的推广小程序。保存前验证当前目录和草稿版本，已有明确链接指向冲突时拒绝选错。

每份草稿共用一个推广目标（延续现有单应用输入），选择将本批次已确认推广链接与 Mini 的对应关系保存在租户内独立缓存，以完整链接摘要为键，不以版权方为键。不同链接只有明确标识或用户确认才能建立关系。已配置的历史链接迁移为对应关系；不改既有广告或冻结请求。选取后各目标账户分别验证可用性。

场景读取使用现有有界任务和完整分页证据，Mini 目录支持分页名称选择；读取页面不触发远端写入。选择属于可幂等恢复的草稿修改，保存后继续准备。管理员旧手填入口退出普通流程。
